# バター：設定動画の分析と描画への反映

資料: ユーザー提供の「バターの設定資料.mp4」。長さ333.028秒、2730×1260、約60fps。従来の3枚の静止画と合わせて確認した。

## 確認方法

全編を12秒間隔の28枚で見渡し、代表15場面を元の解像度で抽出した。通常衣装の動きは20・21・22・23・25・26秒も確認した。後半のプロフィールと記録は画面内の文章を読み取った。音声の逐語書き起こしは行っていない。

- 0〜約60秒: 通常衣装の待機・表情変化・身体の動き。
- 約60〜126秒: 別衣装。サングラス、アイス、オレンジ系衣装は通常衣装へ混ぜない。
- 約126〜290秒: ボイス一覧に伴う表情と台詞表示。途中で通常衣装と別衣装が切り替わる。
- 294秒: プロフィールと通常衣装の全身。
- 302・310秒付近: 記録。

抽出画像は `out/butter-adventure/video-study/` に保存する。動画やフレームの画素は作品データには含めない。

## 性格を表現へつなげる

294秒のプロフィールでは、明るく献身的で、友達を作りたがる性格が説明されている。他者と遊ぶこと、新しい友達を作ることを好む。302秒付近の記録では、親しくなるとついてくることや、関係を悪くしないように努めることが描かれている。

そのため、作品では相手を誘うような手振りと開いた笑顔を保ち、しっぽを嬉しそうに上げる。パチンコは誰かへ向けず、脇に持つ。動画の泣き顔・目を回した顔は表情の可動範囲の参考とし、依頼された「元気はつらつ」の表現へは持ち込まない。

## 判断の限界

動画はゲーム画面の収録で、厳密な三面図ではない。ポーズ・表情・遠近による変形があり、静止画の比率をすべての姿勢へそのまま適用できるわけではない。今回の作品は設定に沿った別ポーズの解釈であり、ピクセル単位の一致を主張しない。


描画元は `examples/butter-adventure.ts`。最終画像、JSON、SVGと局所拡大は `out/butter-adventure/` に保存する。

## ライフセーバー衣装の別作品

追加で1:10・1:18・1:26・1:34・1:42・1:50・1:58・2:04の8場面を比較し、1:50を採用した。犬の形のアイスを片手に持ち、もう一方の手を胸元へ上げ、目を細めて舌を少し出す笑顔が特徴。ハートと揺れる髪も喜びを表している。

この場面の顔・頬・口・手の位置を基準に、通常衣装とは別の描画コードを作成した。骨型サングラス、花柄のオレンジと黄色の救命胴衣、犬の顔の首飾り、スイカのバッグ、犬型アイスを描き込んだ。画面下のUIに隠れる足元は1:10の花付きサンダルを参考に補完した。

背景はアイスのカートと海辺として構成。比較用画像は元動画の領域（x=755、y=240、幅875、高さ980）を1000×1120へ拡大したもので、作品にはその画素を含めない。`examples/butter-lifeguard.ts` の曲線と色からPNG・SVGを生成する。
